New to FLEx or starting fresh?

A pre-configured NT Greek project template is included — it has the correct Greek and English writing systems already set up so you can start right away.

How to restore the template in FLEx
  1. Click Save NT Greek project template… above and choose where to save the .fwbackup file.
  2. Close this app.
  3. Open FLEx → File → Project Management → Restore a Project.
  4. Select the .fwbackup file you just saved.
  5. Close FLEx, then open this app again.
