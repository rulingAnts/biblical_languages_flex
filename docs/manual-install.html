Manual Install — Advanced Users

The Windows installer (.exe) handles everything automatically and is recommended for most users. This page is for users who prefer to install components manually, are running on a non-standard setup, or want to understand exactly what the installer does.

What you need

  1. FLEx (FieldWorks Language Explorer) — the linguistic database environment.
    Download from SIL (Windows only).
  2. Python 3.x with the Python Launcher (py.exe).
    Download from python.org. When installing, check "Add Python to PATH" and ensure the Python Launcher option is selected (it is by default).
  3. flextoolslib — the Python package that bridges Python to FLEx's C# data layer.
    Install via pip (see below).
  4. FLExTools application files — the GUI launcher that runs FLEx utility modules.
    Download the latest release zip from GitHub.
  5. Split_Slash_Glosses.py — our module file.
    Download from the latest release.

Step 1 — Install Python

Download and run the Python installer. On the first screen:

  • Check "Add Python to PATH"
  • Leave "Install launcher for all users" checked (default)

Verify the install by opening a command prompt and running:

py --version

You should see something like Python 3.13.3.

Step 2 — Install flextoolslib

Open a command prompt and run:

py -m pip install flextoolslib

This installs the Python package that lets FLExTools communicate with FLEx's internal data layer (LCM). It is downloaded from PyPI and has no other system dependencies.

Step 3 — Install FLExTools application files

  1. Download the latest FlexTools_*.zip from the FLExTools releases page.
  2. Extract the zip. Inside you will find a FlexTools\ folder.
  3. Copy the contents of that FlexTools\ folder to: 
    %LOCALAPPDATA%\FLExTools\
    (Paste that path into the Windows Explorer address bar to navigate there. Create the FLExTools folder if it does not exist.)
  4. The result should look like: 
    %LOCALAPPDATA%\FLExTools\
  FlexTools.py
  scripts\
  Modules\
  ...
Note: FLExTools does not have a traditional installer of its own — it is just a folder of Python files. The GUI is launched by running FlexTools.py with the Python Launcher (see Step 5).

Step 4 — Install the Split Slash Glosses module

  1. Download Split_Slash_Glosses.py.
  2. Copy it into your FLExTools Modules folder: 
    %LOCALAPPDATA%\FLExTools\Modules\
    (Create the Modules folder if it does not exist.)

Step 5 — Create a shortcut to launch FLExTools (optional but recommended)

FLExTools is launched by running:

py "%LOCALAPPDATA%\FLExTools\FlexTools.py"

To make this easier, create a Start Menu shortcut:

  1. Right-click the Desktop and choose New → Shortcut.
  2. For the location, enter: 
    %windir%\py.exe "%LOCALAPPDATA%\FLExTools\FlexTools.py"
  3. Name it FLExTools and finish.
  4. Optionally move it to %APPDATA%\Microsoft\Windows\Start Menu\Programs\ to appear in the Start Menu.

Step 6 — Use the module

Important: FLExTools opens the FLEx project database directly. FLEx must be completely closed before launching FLExTools, and reopened afterward to see the changes.
  1. Import your passage into FLEx using the NT Greek Interlinear Import Tool.
  2. Close FLEx.
  3. Launch FLExTools (via the shortcut or by running py "%LOCALAPPDATA%\FLExTools\FlexTools.py").
  4. In FLExTools, select your project from the drop-down at the top.
  5. Find Split Slash Glosses in the module list and click Run.
  6. Close FLExTools, then reopen FLEx to see the updated glosses.

Uninstalling

To remove the module, delete Split_Slash_Glosses.py from the Modules folder.

To remove FLExTools, delete the %LOCALAPPDATA%\FLExTools\ folder and run:

py -m pip uninstall flextoolslib

To remove Python, use Settings → Apps and uninstall the Python entry.

To remove FLEx, use Settings → Apps and uninstall FieldWorks.
