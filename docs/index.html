📖 New Testament Greek FLEx Interlinear Import Tool (Web-only)

This tool generates an interlinear .flextext file for any New Testament Greek passage that you can import directly into FieldWorks Language Explorer (FLEx). The file includes Greek words, morphological parsing, lemmas, and English glosses — ready for text charting right away.

Everything runs in your browser — no account or server required. The page works offline once it has been loaded.

Tip: Open this page via http(s) (e.g., using the local test server) so JSON can load. File URLs often block fetch.

Tip: for the easiest import into FieldWorks, use the FLEx Project template in the Downloads section below.

Complete Workflow

This tool is one part of a larger workflow for preparing NT Greek interlinear texts in FLEx for discourse analysis. Here is the full picture from start to finish.

Phase 1 — One-time setup

Do these steps once before your first import.

  1. Install FLEx (FieldWorks Language Explorer)
    Download and install FLEx from SIL (Windows only). FLEx is the linguistic database and text-charting environment this whole workflow is built around.
  2. Install FLExTools
    Download and install FLExTools — a free utility that lets you run Python scripts directly against your FLEx project data.
  3. Install the FLEx Gloss Splitter module
    This module (built for this project) splits multi-sense glosses like in/on/at into individual candidate glosses after import, marking each word blue so you can approve the correct meaning. Install it into FLExTools using either method below.
    ⬇ Download Installer (.exe)   ⬇ Download .py file
    Show installation instructions

    Installer (recommended): Run FLExGlossSplitterModuleSetup.exe. It will locate your FLExTools Modules folder automatically (or prompt you to browse). Restart FLExTools when done.

    Manual: Copy Split_Slash_Glosses.py into your FLExTools Modules folder (e.g. C:\Users\you\AppData\Local\FLExTools\Modules\). Restart FLExTools when done.

  4. Open the NT Greek project template in FLEx
    Download the pre-configured FLEx project below and restore it. It includes the correct Greek and English writing systems, morphological category lists, and pre-built text chart templates — saving significant setup time.
    ⬇ Download FLEx Project Template (.fwbackup)

    In FLEx: File → Project Management → Restore a Project and select the downloaded file.

Phase 2 — Import and analyse a passage

Repeat these steps for each passage you want to study.

  1. Generate the .flextext file
    Use the tool at the top of this page: select a book, enter a passage reference, click Load, then click Generate .flextext and save the downloaded file.
  2. Import into FLEx
    In FLEx, open your NT Greek project and go to the Texts & Words area. Choose File → Import → FLExText interlinear… and select the .flextext file you just saved. The passage will appear as a new interlinear text with Greek words, morphological parsing, and English glosses already filled in.
  3. Split multi-sense glosses with FLEx Gloss Splitter
    Many words import with slash-separated glosses (e.g. in/on/at) reflecting all possible senses. Open FLExTools, select Split Slash Glosses from the module list, choose the text(s) you just imported, and run it. Each multi-sense word is split into individual candidate glosses and marked blue — ready for your approval.

    You must close FLEx before running FLExTools and reopen it afterward.

  4. Approve glosses for each blue word
    Back in FLEx, work through the blue (unapproved) words in the interlinear view. Click each one to see the candidate glosses, then select the correct meaning for this context. The word turns black once approved.
  5. Analyse the text with the Text Chart tool
    Switch to the Text Chart view in FLEx. The passage is ready to chart for clause structure, participant tracking, discourse features, and more.
  6. (Optional) Visualise and export with FDAT
    Export your completed text chart from FLEx and load it into FDAT (FLEx Discourse Analysis Tool) — a companion web app for visualising and exploring discourse structure across a passage or book.
