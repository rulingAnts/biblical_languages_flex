📖 New Testament Greek FLEx Interlinear Import Tool (Web-only)

This tool generates an interlinear .flextext file for any New Testament Greek passage that you can import directly into FieldWorks Language Explorer (FLEx). The file includes Greek words, morphological parsing, lemmas, and English glosses — ready for text charting right away.

Everything runs in your browser — no account or server required. The page works offline once it has been loaded.

Tip: Open this page via http(s) (e.g., using the local test server) so JSON can load. File URLs often block fetch.

Tip: for the easiest import into FieldWorks, use the FLEx Project template in the Downloads section below.

How to use

  1. Select a book from the dropdown and enter a passage in the reference box (e.g. 1:1-1:3, 5, 3:16).
  2. Click "Load" to fetch the passage data.
  3. Wait for the blue preview box above to populate — this confirms the data loaded successfully.
  4. Click "Generate .flextext" and save the downloaded file.
  5. Download the FLEx Project template (see Downloads below) and open it in FLEx.
  6. In FLEx, open the Interlinear Texts view, then choose File → Import → FLExText interlinear… and select your saved file.
  7. Clean up word glosses as needed — the auto-generated ones are a starting point.
  8. Use the Text Chart tool to analyse the passage.
  9. (Optional) Export your FLEx text chart data and explore it further with FDAT (FLEx Discourse Analysis Tool), a companion web app for visualising and analysing discourse structure.
  10. Have suggestions, bug reports, or want to contribute? Visit the project on GitHub to open an issue or pull request.
